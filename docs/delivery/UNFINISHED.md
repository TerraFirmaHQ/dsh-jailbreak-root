# 未完成与卡点

这些不是「以后再优化」。是这一轮里做不到或不能假装做完的项。

1. **真机验收没有做。** 这台环境没有连上 PMS110 Ace7 Pro，没有 ARM64 模拟器系统镜像。P0 的实现和 host 单测不能写成 P0 全通过，也不能写成 Ace7 实测。
2. **D9 的 300MB 门槛没有在手机上量。** `PERF-host.txt` 是本机 JVM 上 20 轮摘要函数的内存差，不是 20 轮真实工具会话，更不是 14.2G/15.1G 那台手机。
3. **引擎侧上下文缓存。** 工具输出超过 64KB 会进 spool，回复里只放摘要。DSH 进程里的模型上下文没有单独的「空闲 90 秒释放」接口。90 秒释放的是本应用的 spool 文件和已结束的后台任务记录，发生在下一次工具调用或 root 桥关闭时，没有常驻定时器。
4. **eta 待确认。** 见 `REUSE.md`。没有选定同名插件。
5. **P2-5 的 1272×2772 和 165Hz 没有上机。** 刷新率代码本来就是取当前分辨率下系统列出的最高模式（`MainActivity.applyRefreshRate`），没有写死 120。输入框仍可多行，改成单行会截断正在输入的消息。状态条里已有 `maxLines: 1` 的条目没有改成多行。
6. **G1 的设置索引行还在。** 「检查更新」这个索引锚点还在关于页，标题仍是索引文案，右侧和开关说明是「当前为锁定版本」。点它只弹出这句话，不联网、不下载、不弹升级表。启动检查直接返回。设置首页不再挂「有新版本」标记。
7. **签名。** 本机构建会先被 Flutter 打上调试签名，交付前去掉 APK Sig Block。安装连续性要盒子用原来的 key 重签。本机调试证书不是手机上的那个。
8. **不承诺零 bug。** host 单测覆盖了分类器 12 例、只读开关不放行写入、root 关闭时 check_root 不调用 runner。没有覆盖真机 su、KernelSU 弹窗和 ColorOS 图标底板。
